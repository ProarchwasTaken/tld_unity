# The Purpose of this Website
Good evening, Ladies and Gentlemen. This website is meant to serve as a 
convenient place to access every entry in the True Human Tribulation
series. It's also a place to view art and videos made for the series, and
as a place to read news and updates for uncoming entries.

# The Plan

## Features
The site is basically a glorified blog. I don't intend to add anything
too complex like a database or a forum. My focus will be fully on making 
it real first, then making it good later.

## Style
Since I'm new to this, the aesthetic I'm gonna try to go for is that of 
Skeuomorphism or Dark Aero. Basically, I want the website to look like it 
was from the 2010s, or at least look like a website you'd usually visit at 
the dead of night.
